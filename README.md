# School Buddy

Persoonlijke studieplanner. Zet je toetsen en leerstof erin, stel in hoe en wanneer je het liefst leert, en School Buddy maakt je planning, met een agenda en herinneringen.

Alles wordt lokaal in je browser bewaard. Er is geen server.

## Ontwikkelen

```bash
npm install
npm run dev
```

```bash
npm test
```

Elke push naar `main` wordt automatisch gebouwd en op GitHub Pages gezet.
